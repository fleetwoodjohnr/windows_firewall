## What changed

- Replaced checkbox-like security controls with clear Windows switches that match
  the Fedora application's interaction language: red/left is Off and green/right
  is On. Colour reports state, not whether enabling a feature is recommended.
- Made every machine-setting switch report confirmed Windows state. A click no
  longer moves the control until the change succeeds; cancelling UAC, cancelling
  a warning, a timeout, or a Windows policy refusal leaves the original state in
  place and cannot trigger a second opposite request.
- Stopped the GUI, privileged helper, scanner service, status refreshes, and
  installer extras from creating unintended CMD or PowerShell windows. UAC,
  Windows Security, web links, and the graphical setup wizard still open when
  explicitly requested.
- Expanded in-app explanations for scan choices, automatic download scanning,
  update verification, firewall switch colours, compatibility risks, and what is
  retained during upgrades.

## Installing and upgrading

Download `WinHardenSetup-1.2.1.exe` and its `.sha256` file. This unsigned Windows
11 x64 installer may show an Unknown publisher warning; compare the SHA-256 hash
before running it. Python, Qt, and the other runtime dependencies are included.

Upgrading from 1.2.0 keeps application preferences, watched folders, download and
scan history, queued scan records, and the original-settings restoration journal.
